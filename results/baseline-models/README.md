# Baseline Model Results

Pre-computed evaluation results from running the four baseline algorithms (RevFinder, cHRev, TurnoverRec, Sofia) on the subject repositories.

## How to reproduce

1. Crawl repository data using `data-collection/`
2. Run the baseline models using `baseline-models/`
3. Evaluation results are saved automatically to JSON

## Files

Place the per-repository evaluation result JSONs in this directory.
